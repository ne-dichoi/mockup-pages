# 문제 기록 (trouble)

방금 발생한 문제(오류, `BLOCKED_*`/`ERROR` 마커, 반복되는 실패 등)를 `TROUBLESHOOTING.md`에 사례로 남긴다.

> 참고: 의미 있는 문제가 **해결되면 보통 Claude가 자동으로** 기록한다(CLAUDE.md "문제 자동 기록" 규칙). 이 스킬은 **수동으로** 특정 문제를 남기고 싶을 때 쓴다.

## 절차

1. 방금 상황을 바탕으로 **증상·원인·해결(또는 시도)**을 정리한다. 불확실하면 사용자에게 한두 가지만 확인한다.
2. 저장소 루트 `TROUBLESHOOTING.md`의 "사례" 아래에 **템플릿 형식**으로 항목을 추가한다:
   ```
   ## <짧은 제목>
   - 증상:
   - 원인:
   - 해결:
   - 관련: (마커/명령/상황, 선택)
   ```
3. 사용자에게 초안을 보여주고 확인을 받는다.
4. 반영은 **브랜치 흐름**으로 한다: 이미 작업 브랜치에 있으면 `/publish`(→ git-helper task=publish)로 올리고, `main`에 있으면 `/publish`의 자동 브랜치 이동으로 처리된다.

## 주의

- **git이 블록 상태(진행 중 충돌·다이버전스)일 때는 기록을 위해 무리하게 publish하지 않는다.** 먼저 원래 문제를 해소하거나 담당 개발자에게 넘긴 뒤, 별도 사이클로 기록한다.
- 문서 추가도 저장소 변경이므로 `main`에 직접 커밋/올리지 않는다(가드 적용).
