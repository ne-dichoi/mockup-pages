# 최신 받기 (sync)

기획자가 목업 작업을 **시작하기 전** 최신 내용을 받아오는 스킬이다. git을 몰라도 되게, 아래를 대신 수행하고 결과를 한국어로 보고한다.

## 절차

1. 현재 브랜치를 확인한다.
   ```bash
   git branch --show-current
   ```
   `main`이 아니면 `git checkout main`으로 이동한다.

2. 최신 내용을 받아온다.
   ```bash
   git pull --ff-only origin main
   ```

3. **실패했다면** (보통 아직 안 올린 로컬 변경이 있어서 발생):
   - 임의로 `git stash`·`git reset`·`git checkout -- .` 등 **변경을 지우는 동작을 하지 말 것.**
   - 한국어로 상황을 설명하고 선택지를 제시한다:
     "받아오기 전에 지금까지 작업한 변경이 남아 있습니다. 먼저 **올리기(publish)**로 저장한 뒤 다시 시도하거나, 이 변경을 버려도 되는지 알려주세요."

4. **성공했다면** 결과를 한국어로 보고한다:
   - 이미 최신이면 "이미 최신 상태입니다."
   - 새 내용을 받았으면 어떤 커밋이 들어왔는지 `git log --oneline -5`로 간단히 요약한다.

## 원칙

- git 명령이 실패하면 원문 오류를 숨기지 말고 한국어 설명과 함께 보여준다.
- 확실하지 않으면 사람에게 묻는다. 데이터(작업물)를 잃게 하는 동작은 절대 하지 않는다.
