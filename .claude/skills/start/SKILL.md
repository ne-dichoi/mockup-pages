# 작업 시작 (start)

목업 작업은 항상 **전용 브랜치**에서 한다(`main`에서 직접 작업 금지). git 작업은 **`git-helper` 서브에이전트(Sonnet)**가 처리한다.

## 지시

1. 사용자에게 **"무슨 작업인지 한 단어로"** 짧게 물어본다 (예: `주문상세`, `장바구니`). 이미 사용자가 말했으면 다시 묻지 않는다.
2. Agent 도구를 `subagent_type: git-helper`로 호출하고 다음을 전달한다:

   > task=`start`, 작업 이름=`<사용자가 말한 값>`. 저장소 루트에서 `bash scripts/git-start.sh "<작업 이름>"`을 실행하고, 출력 마지막 줄 마커에 따라 한국어로 결과를 보고해줘.

3. 에이전트가 돌려준 결과(생성된 브랜치명 등)를 사용자에게 그대로 전한다. 직접 git 명령을 실행하지 않는다.
