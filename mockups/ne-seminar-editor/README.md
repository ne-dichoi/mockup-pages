# 혼강 세미나 에디터

매월 혼강 세미나 **상세페이지 1종 + 홍보 배너 7종**을 디자이너 없이 직접 제작하는 도구입니다.

`index.html`을 브라우저로 열면 바로 실행됩니다. 설치·서버 불필요, 인터넷이 끊겨도 동작합니다.

---

## 화면 구성

- **왼쪽** 미리보기 / **오른쪽** 편집 — 오른쪽에서 고치면 왼쪽에 즉시 반영됩니다.
- 왼쪽 위 `상세페이지` · `배너 7종` 탭으로 전환합니다.
- `이미지 만들기` → **상세페이지 전체 1장** / **섹션별** / **배너 7종** 중 선택.
  세로가 긴 상세페이지는 업로드가 까다로우니 웹 게시용이면 섹션별을 권합니다.

## 무엇을 바꿀 수 있나

| 항목 | 편집 위치 |
| --- | --- |
| 배경·강조 색 | 테마 컬러 (프리셋 6종 또는 직접 지정) |
| 상단 문구 | 표지 |
| 세미나 날짜·시간·제목·강사 | 세미나 — `＋` / `−` 로 회차를 늘리고 줄임 |
| 강사 사진 | 세미나 > 각 카드 |
| 참석 혜택 | 참석 혜택 — `＋` / `−` 로 항목을 늘리고 줄임 |
| 신청 안내·푸터 | 신청 안내 · 푸터 |

**문구 안에서 강조**하려면 그 부분을 `*별표*`로 감쌉니다.
`시작되는 2학기, *9월*의 첫 수업` → `9월`만 강조색이 됩니다.
글자를 드래그한 뒤 `✦ 선택 강조` 버튼을 눌러도 됩니다.

## 손대지 않아도 되는 것

- **날짜** — 세미나 날짜만 바꾸면 달력 위치, 요일 강조, `10.15 THU`, 일정 목록,
  제목의 월 표기(`10월 세미나 일정…`)가 전부 따라갑니다.
- **공휴일** — 일요일과 신정·삼일절·어린이날·현충일·광복절·개천절·한글날·성탄절은 자동입니다.
  설·추석·대체공휴일처럼 해마다 바뀌는 날짜만 직접 입력하세요.
- **강사 사진** — 올리면 배경을 자동으로 지우고, 얼굴 크기를 재서 카드마다 같은 비율로 맞춥니다.
  원본이 전신이든 상반신이든 동일하게 들어갑니다.
- **배너 7종** — 상세페이지의 색과 문구를 그대로 따라갑니다. 따로 편집할 것이 없습니다.

## 다음 달 작업

1. `설정 저장` → JSON 파일을 받아 둡니다.
2. 다음 달에 `불러오기` → 그 파일을 선택합니다. 사진까지 그대로 복원됩니다.
3. 날짜·문구·사진만 교체합니다.

브라우저에 자동 저장되지만 **PC가 바뀌면 사라집니다.** 매달 JSON을 받아 두세요.

## 알아둘 점

- `[B&G]메인_400x450` 배너는 **배경이 투명**합니다. 관리자에 배경 색값을 직접 넣는 방식이라,
  내보낸 파일명에 색값이 붙습니다. (`[B&G]메인_400x450_#7935F6.png`)
- `[Books]이벤트리스트` 배너는 가이드가 정해져 있어 「혼강 세미나」 보라색(`#803693`)이
  테마 색과 무관하게 고정됩니다.
- 사진 배경 제거는 **단색·스튜디오 배경**에서 가장 잘 됩니다. 결과가 어색하면
  `제거 강도` 슬라이더를 조절하거나, 배경이 이미 없는 PNG라면 체크를 끄세요.
- 디자인 원본의 Paperlogy·Pretendard 폰트가 설치되어 있지 않으면 대체 폰트로 표시됩니다.
  글자 모양을 원본과 정확히 맞추려면 두 폰트를 설치하세요.
