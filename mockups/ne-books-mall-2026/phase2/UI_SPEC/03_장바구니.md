# 장바구니 UI 스펙 (파일: 장바구니.html)

> **🟢 디자인 반영(2026-08)**
> - **모바일 레이아웃(≤767)**: PC 7컬럼 행을 grid-area 리플로우 = 회색박스 썸네일(105×105, 책 55×72)·**체크박스는 썸네일 좌상단 오버레이**, 제목+×(우상단), 하단에 스테퍼(100×36)+`10%`/단가(13,500원). 상단바=`전체선택`+`삭제` 단일. PC 요약 사이드바는 모바일 미노출 → **하단 고정 CTA `총 N원 주문하기`**(푸터 도달 시 푸터 위 20px 도킹).
> - **빈 장바구니(모바일, UC-BUY-12)**: 회색 원(80)+`!` 아이콘 → `장바구니가 비어 있습니다`(14 SemiBold) → 서브(12 #a9a9a9) → 빨강 `쇼핑계속하기`(**목적지=메인 index 확정**). 빈 상태 시 상단바·안내문·CTA 모두 숨김.
> - **삭제 확인 팝업(UC-BUY-07, 신설)**: 개별 `이 상품을 삭제하시겠습니까?` / 선택 `선택한 상품을 삭제하시겠습니까?`(0개 선택 시 `삭제할 상품을 선택해 주세요.`) / 전체 `장바구니를 모두 비우시겠습니까?` — 스타일 팝업(취소/삭제).
> - **주문 차단 팝업(UC-BUY-11, 신설)**: 선택 0건 → `주문할 상품을 선택해 주세요.` / 일시품절 포함(전체주문·모바일 CTA) → `일시품절된 상품이 있어 주문이 불가합니다.` 차단.
> - **절판 자동 제외(POL-SALE, 신설)**: 담긴 상품이 **절판(판매중단)되면 장바구니에서 무조건 삭제** + 토스트 `절판된 상품이 장바구니에서 제외되었습니다.`(진입 시 `.citem.discontinued` 자동 제거).

## 1. 화면 개요
- **구성 UC**: UC-BUY-06(상품 조회) · UC-BUY-07(선택/삭제) · UC-BUY-08(금액·배송비 계산) · UC-BUY-09(비회원 쿠키) · UC-BUY-10(로그인 병합) · UC-BUY-11(주문하기 선택/전체) · UC-BUY-12(Empty) · UC-BUY-03(수량 변경) · UC-BUY-05(판매상태별 제어) · UC-INFO-17(일시품절 표시) · UC-PNT-07(추가 할인/적립)
- **진입경로**: GNB 장바구니 아이콘, 교재상세/목록 담기 후 이동, 헤더 cart-badge
- **로그인 요건**: 조회·담기·수량·삭제는 **비회원 가능**(Session 쿠키+서버DB, POL-CART). **주문하기는 회원 전용** — 비회원은 로그인 유도(UC-BUY-11, POL-MEMBER)
- **레이아웃**: 2단 그리드 `cart-grid` = 좌측 목록(1fr) + 우측 결제예상 요약(360px sticky). 태블릿 이하(≤768) 1단 전환, 우측 카드 static

## 2. 화면 구성 (영역별)

### 2-1. 상단 컨트롤 바 (`.cart-bar`)
- **관련 UC**: UC-BUY-07
- **UI**: 좌측 `전체선택` 체크박스(`#selAll`, 기본 checked), 우측 `선택 삭제`/`전체 삭제` outline 버튼. 구분선 `--line`
- **정책**: POL-CART. 전체선택은 판매 가능 상품만 대상(일시품절/disabled 제외 — HTML 구현됨)
- **인터랙션**: 전체선택 토글 → 활성 행 체크 일괄 변경 → 금액 재계산. 개별 체크 변경 시 전체선택 상태 sync

### 2-2. 상품 목록 (`.cart-list` / `.citem`)
- **관련 UC**: UC-BUY-06, UC-BUY-03, UC-BUY-05, UC-INFO-17
- **행 구성(7컬럼)**: 체크박스 · 썸네일(`.cthumb`) · 상품명(`.cname`) · 가격(`.cprice` 정가 취소선+판매가+할인/적립 note) · 수량 스테퍼(`.qty`) · 소계(`.csum` 금액+적립예정) · 삭제(`.cdel`)
- **가격 표기(POL-PRICE)**: 정가 취소선 / 판매가 강조 / "(10%할인+150P 적립)" note. 적립은 정가 기준
- **수량(UC-BUY-03)**: −/입력/+ 스테퍼, min=1. 실시간 소계 갱신
- **판매상태(UC-BUY-05, UC-INFO-17)**: 일시품절 행 → `.soldout` 클래스, 체크박스/수량 스테퍼 disabled, 썸네일 딤+배지. **담기(목록 유지)는 가능, 주문 대상에서 제외**
- **인터랙션**: +/− 클릭·직접입력 → recalc, 삭제(×) → 행 제거 후 recalc

### 2-3. 안내 문구 (`.cart-notes`)
- 포인트는 주문/결제 페이지 적용 안내, 3만원 미만 배송비·도서산간 +2,500 안내(POL-DELIVERY)

### 2-4. 결제 예상 금액 요약 (`.cart-side`, sticky)
- **관련 UC**: UC-BUY-08, UC-BUY-11
- **UI**: 총 상품금액 / 상품 할인금액(−) / 배송비 / 총 N건 합계(강조 red) / 적립 예정 P / `선택상품 주문`(dark) · `전체상품 주문`(primary)
- **계산(UC-BUY-08, POL-DELIVERY)**: 상품금액=Σ(정가×수량), 할인=Σ((정가−판매가)×수량), 배송비 = 상품금액 ≥30,000 → 0, 0<금액<30,000 → 2,500. 선택된 판매중 상품만 합산
- **인터랙션**: sticky 고정 시 그림자(`.stuck`). 주문 버튼 → 주문결제.html 이동

## 3. 상태·예외
- **Empty(UC-BUY-12)**: 0건 시 `.cart-empty` 노출 — 안내문구+`쇼핑계속하기`. **추천 교재 미노출**(구현됨). 확정 문구 "장바구니가 비어있습니다.", 버튼 목적지 **메인 페이지**
- **일시품절(UC-INFO-17/BUY-05)**: 플래그 표기+구매/수량 비활성, 담기(목록)는 유지, 주문 제외
- **판매중단(절판)(UC-BUY-05)**: 담기·주문 모두 불가, Front 라벨 "절판" — 현재 미표현
- **삭제 확인(UC-BUY-07)**: 개별 "이 상품을 삭제하시겠습니까?", 선택 "선택한 상품을 삭제하시겠습니까?" 확인 얼럿 후 실행, 취소 시 유지
- **주문 차단(UC-BUY-11)**: 선택 0건 → 주문 비활성 / 선택에 일시품절·구매제한 포함 → 전체 차단, "일시품절된 상품이 있어 주문이 불가합니다." / 비회원 → 로그인 유도 후 장바구니 복귀
- **수량 한도(UC-BUY-03)**: 최대 999·재고 초과 시 "최대 OO개까지 담을 수 있습니다." 보정
- **비회원/병합(UC-BUY-09/10)**: Session 쿠키 만료 시 비움, 로그인 병합 시 "장바구니 상품이 합쳐졌습니다." 토스트
