## 2. 화면 구성 (탭별)

### 2-1. 공지사항 탭 (`#cc-notice` / UC-CS-01)
- **관련 UC**: UC-CS-01 · POL-COMMON
- **UI 요구사항**
  - 필터바 `.qa-filter`: 좌측 분류 밑줄탭 `.pt-tabs`(전체/공통/ELT/초중고(영어)/교과서 관련/수험·일반/수학·국어) + 우측 키워드 검색 `.oh-search`(입력 + 지우기 × + [검색]).
  - 목록 표 `.nt-table`: 헤더(NO·분류·제목·등록일·조회) + 행 `.nt-tr`. 상단공지는 NO 컬럼에 '공지' 뱃지 `.nt-badge`(빨강 테두리 알약)로 최상단 노출, 일반 행은 NO 숫자.
  - 페이저 `.pager`(이전/1~5/다음).
- **정책(POL)**: 상단공지 우선·최신 등록순, 페이지당 10개 → POL-COMMON. 2026-07-28 변경대로 필독/중요/안내 뱃지 컬럼·필터 없음(말머리는 제목 텍스트로 직접 기재).
- **인터랙션**: 행 클릭 → `공지사항상세.html`. 밑줄탭 그룹 토글, 검색 인풋 × 지우기.

### 2-2. FAQ 탭 (`#cc-faq` / UC-CS-03)
- **관련 UC**: UC-CS-03 · POL-COMMON
- **UI 요구사항**
  - 필터바: 분류 밑줄탭(전체/사이트 이용/회원정보/NE Point/교재/부가 서비스/취소환불/배송/기타) + 검색영역 드롭박스 `.oh-sel` + 키워드 검색.
  - 아코디언 `.faq-table`: 항목 `.faq-q`(NO·구분·Q 마커·제목·chevron) → 답변 `.faq-a`(A 마커 + 본문, 첨부 링크 가능). 상단선은 진한 --ink.
- **정책**: 분류는 커머스(주문결제·취소환불·배송) 포함, '래빗 포인트' 제거. 분류 선택 2경로(탭+드롭박스) → POL-COMMON.
- **인터랙션**: 질문 클릭 시 답변 펼침/접힘(`.faq-item.open`).

### 2-3. 이벤트/신간·개정/세미나 탭 (`#cc-event` / UC-CS-04)
- **관련 UC**: UC-CS-04 · POL-EVENT · POL-MEMBER
- **UI 요구사항**
  - 한 페이지 통합(콘텐츠 유형 서브탭 없음). 필터바: 카테고리 밑줄탭(전체/공통/ELT/초중고(영어)/교과서 관련/수험·일반/수학·국어) + 진행/종료 상태 셀렉트 `.oh-sel`.
  - 카드 그리드 `.ev-grid`(3열): 썸네일 `.ev-thumb` + 유형 뱃지 `.ev-badge.type`(이벤트/세미나/신간·개정) + 카테고리 뱃지 `.ev-badge.cat` + 제목 + 설명 + 상태 `.ev-state`(진행중=빨강/종료=회색) + 기간.
  - **썸네일 크롭 규칙(디자인 지정)**: 원본 이미지는 세로 긴 `7:8` 비율. 목록 카드에서는 가로 짧은 프레임 `.ev-thumb`(`aspect-ratio:437/280`, `radius 16`)에 `object-fit:cover; object-position:top`으로 담아 **원본의 위쪽 영역만** 노출한다(아래쪽 잘림). 이벤트/신간·개정/세미나 카드 공통. → 디자인 가이드 `DESIGN_TOKENS.md §18` 참조.
  - 페이저.
- **정책**: 소스 플래그(UC-ADM-SITE-14 이벤트·신간개정 / UC-ADM-SITE-11 세미나) 원 등록시간 순 통합, 참여대상(전체/회원/교강사) 노출 제어(이벤트·신간개정 한정, 세미나 제외) → POL-EVENT. 고객센터=전체 / 마이페이지 '이벤트/세미나' 탭=본인 신청분(UI 동일).
- **인터랙션**: 카드 클릭 → 유형별 상세(`이벤트상세.html`·`신간개정상세.html`·`세미나상세.html`).

### 2-4. 교재 오류정정 탭 (`#cc-errata` / UC-CS-05)
- **관련 UC**: UC-CS-05 · POL-MEMBER
- **UI 요구사항**

  - 필터바: 카테고리 밑줄탭 + 우측 버튼 [교재 오류 신고하기]`.btn-report` · [교과서 콘텐츠 FAQ]`.btn-cfaq`.
  - 목록 표 `.nt-table`(NO·분류·제목·등록일·조회) + 페이저.
- **정책**: 신고 작성=회원(비회원 로그인 유도) → POL-MEMBER. 교과서 콘텐츠 FAQ → UC-CS-17 연계.
- **인터랙션**: 행 클릭 → `오류정정상세.html`.

### 2-5. 1:1 문의 탭 (`#cc-qna` / UC-CS-08·09·10)
- **관련 UC**: UC-CS-08 등록 · UC-CS-09 주문번호 연계 · UC-CS-10 비회원 · POL-INQUIRY · POL-COMMON
- **UI 요구사항 (고객센터=작성 폼 직행, 목록/조회 없음)**
  - 문의 전 안내박스 `.iq-preinfo`: 링크 3종 [도움말(FAQ)] [교재정오 알림] [교과서 콘텐츠 FAQ].
  - 폼 `.iq-form`(라벨 160px + 필드 2열 표):
    - 상담유형 라디오(일반문의 / 교재 오류신고 / 주문·배송 관련 문의)
    - 상담분류 셀렉트(필수)
    - **교재명**(교재 오류신고 선택 시 노출 `#iqBookRow`): 카테고리 셀렉트 + 상품명 검색 인풋 + [검색] + 선택 결과(표지·제목·삭제) — 상품 카탈로그 조회
    - **주문번호/상품**(주문·배송 선택 시 노출 `#iqOrderRow`): 주문번호 셀렉트(NB… 본인 주문). **🟢 반영(2026-08)**: 상담분류=**취소/환불** 선택 시에만 **[문의 상품 선택] 버튼 + 안내문**(`* 원활한 상담을 위한 상품 선택으로 본 페이지에서 바로 반품/환불처리가 되지 않습니다.`) 노출 → 버튼 클릭 시 **환불 문의 상품·수량 선택 표**`.pr-refund`(선택/상품명/수량 3열, 좌우 세로선 없음·스크롤 없이 전체 노출, 체크박스·스텝퍼 + `문의 상품 수량 합계` 푸터)
    - 작성자(회원=고정 표기), 이메일(아이디@도메인 + 도메인 셀렉트, 필수), 휴대폰 + 답변여부 SMS 알림받기, 제목(필수), 내용(필수) + 안내박스(교강사 자료요청·지사안내 링크), 첨부파일(5MB)
  - 하단: 필수 안내 + [등록].
- **정책**: 상담유형·분류 옵션값·첨부·답변통지 → POL-INQUIRY. 주문·배송은 본인 주문만 노출·비회원 미노출 → UC-CS-09. 필수 검증(순차 알럿·스크롤·포커스) → POL-COMMON.
- **인터랙션**: 라디오 변경 → 교재명/주문번호 행 토글. 상담분류=취소/환불 → [문의 상품 선택] 버튼 노출(분류 변경 시 표 숨김). 버튼 클릭 → 환불 문의 상품·수량 표 노출. 체크/스텝퍼 → 합계 갱신.

## 상세 페이지

### D-1. 공지사항 상세 (`공지사항상세.html` / UC-CS-01)
- 대탭(공지사항 활성) + 표 `.nd-table`: 제목 행(분류 알약 `.nd-cat` + 제목 + 등록일) + 본문 `.nd-body` + 첨부파일 행 `.qd-row`. 하단 [목록] `.qd-list-btn`.
- 정책: 상세=제목+등록일+본문+[목록](POL/UC-CS-01). 뱃지(필독/중요) 없음(정책 반영).

### D-2. 교재 오류정정 상세 (`오류정정상세.html` / UC-CS-05)
- 섹션 타이틀 '오류정정' + 표: 제목 행(분류 알약+제목+등록일) + **교재 정보 행** `.ee-info-row`(표지 `.ee-cover` + 교재명·출간일 리스트) + 본문 + 첨부파일 행. [목록].
- 정책: 상세에 교재정보(표지·교재명·출간일) 포함, 첨부는 있을 때만 노출 → UC-CS-05.

### D-3. 이벤트 상세 (`이벤트상세.html` / UC-CS-04)
- 표: 이벤트명 행(이름 + 상태 `.ev-d-status` 당첨자발표) + 기간 행 + 본문 `.ev-d-body`(배너 이미지 + 텍스트 + 당첨자 이미지). [목록].

### D-4. 신간·개정 상세 (`신간개정상세.html` / UC-CS-04)
- 표: 제목 행 + 본문(관리자 등록 이미지 1장). [목록]. (당첨자발표·신청 없음)

### D-5. 세미나 상세 (`세미나상세.html` / UC-CS-04)
- 표: 제목 행(이름+상태) + 주제 행 + 장소/기간·강사 분할행 `.ev-d-split` + 본문(이미지) + **[세미나 신청]** 버튼. 신청 팝업 `.sm-modal`(신청자명 고정 + 세미나 장소 셀렉트 + 직업 + 연락처 + 이메일).

### D-6. 비회원 문의 (`비회원문의.html` / UC-CS-10)
- 대탭(1:1 문의 활성) + 안내박스 `.iq-preinfo.guest`(비회원 안내문구 좌측 + 링크 3종·안내 우측) + 폼.
- 회원 폼과 동일 구조 + 추가: **작성자(이름) 입력**, **자동등록방지(캡차)** `.iq-captcha`(코드+새로고침+입력), **개인정보 동의** `.iq-agree`(필수/선택 각각 목적·항목·기간 고지 + 동의 체크). 내용 안내에 "개인정보 포함 유의" 문구.
- 교재 오류신고 시 상품명 선택 노출, **주문번호/상품 행은 없음**(비회원 주문 데이터 없음). → UC-CS-10.
