목업 페이지

기획·디자인 목업을 폴더 하나로 올리면 자동으로 공개 주소가 생기는 저장소입니다.

무엇을 하는 곳인가요?

mockups/ 아래에 폴더를 만들고 index.html을 넣은 뒤 main에 push하면, GitHub Actions가 자동으로 빌드해 공개 주소에 배포합니다. 별도의 서버 세팅이나 배포 작업이 필요 없습니다.

목업 추가하는 법

  1. mockups/ 아래에 폴더를 하나 만듭니다. 폴더 이름이 곧 URL 경로가 됩니다. (영문·숫자·하이픈 권장)
  2. 그 안에 index.html을 넣습니다. 이미지·CSS 등 필요한 파일도 같은 폴더에 함께 둡니다.
  3. HTML의 <title>에 적은 값이 목록 페이지에 표시되는 이름이 됩니다.
  4. main에 push하면 1~2분 뒤 자동 반영됩니다.
mockups/
  order-detail/
    index.html   → /mockups/order-detail/
    screenshot.png
