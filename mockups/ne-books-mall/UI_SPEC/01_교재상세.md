# 교재상세 UI 스펙 (파일: 교재상세.html)

> NBR 자사몰 개편 · 반응형 단일 사이트. 본 문서는 교재상세 화면의 디자인 UI 스펙 + 내 HTML 갭분석.
> 브랜드 변형본 `oxford.html` 존재(교재상세의 Oxford 테마 변형) — 구조 동일 가정, 본 문서 분석 대상 아님.

---

## 1. 화면 개요

- **구성 UC (18종)**
  - 기본정보/구매: UC-INFO-05(기본정보 영역 재구성), UC-INFO-16(미리보기), UC-INFO-17(일시품절), UC-BUY-01(장바구니 담기), UC-BUY-02(바로구매), UC-BUY-03(수량), UC-BUY-05(판매상태별 구매 제어), UC-BUY-13(찜), UC-PNT-07(추가 할인/적립)
  - 관련정보 섹션: UC-INFO-14(관련정보 Tab/스크롤스파이+우측 구매영역), UC-INFO-06(상세정보), UC-INFO-09(학습법), UC-INFO-11(시리즈), UC-INFO-13(다음단계), UC-INFO-12(추천), UC-INFO-10(후기), UC-INFO-07(정보고시), UC-INFO-08(구매유의사항)
- **진입경로**: 교재목록/검색/메인 카드 클릭, 직접 URL. **비노출(노출여부=N) 상품도 상품코드 URL 직접 접근 시 정상 노출**(삭제 상품만 차단, → POL-SALE, UC-INFO-05).
- **로그인 요건**: 조회·공유·장바구니 담기 = 비회원 포함 전체. **바로구매·찜 = 회원 전용**(비회원 로그인 유도, → POL-MEMBER).
- **페이지 골격**: 교재 기본정보(HERO) → 관련정보 Tab 바(9개, sticky) → Tab 순서와 동일 순서의 9개 섹션(전환형 아님, 앵커/스크롤스파이) → PC는 좌(섹션)·우(sticky 구매영역) 2단.

## 2. 화면 구성 (영역별)

### 2-1. HERO 좌측 — 썸네일/미리보기/부가서비스 (UC-INFO-05·16)
- **UI**: 썸네일(교재관리 필수값, NEW·HOT 배지는 Admin 설정 시만 상단), 미리보기 버튼(URL 등록 시만, 썸네일 우측 하단), 부가서비스 바로가기(Waffle·모바일 학습지원, 연결 시만).
- **정책/차이**: PC = 좌측 커버 **플로팅(sticky) 없음(디자인 확정 2026-08)**. 부가서비스 QR(모바일학습·MP3음원)은 **학습자료 섹션 헤더 우상단(테이블 위)** 에 배치(舊 'HERO 좌측 하단 플로팅'에서 이전). Mobile = 세로 1단, 부가서비스는 **아이콘+명칭**(`.dh-cbtns` 음원듣기·모바일학습)을 썸네일 바로 아래.
- **인터랙션**: 미리보기 클릭 → 등록 URL **새창** 오픈(레이어/뷰어 아님, → UC-INFO-16).

### 2-2. HERO 우측 — 메타~구매버튼 (UC-INFO-05·13·03·02·01·PNT-07)
- **행 구성(위→아래)**: ①메타(브랜드명·카테고리 2단계명·학습대상 시작~종료 범위·Lexile지수·공유하기·찜·찜 개수) ②상품명 ③대표카피 ④가격(할인율·판매가·정가) ⑤출간일정 보기·교재정오 신청 ⑥교재 공지 ⑦학습자료(전체 다운로드+개수, 유형별 다운로드, 넘치면 좌우 스와이프)+교강사 자료 바로가기 ⑧적립안내(Hover)+적립포인트 ⑨배송비안내(Hover)+배송비 ⑩수량(−/+·직접입력·기본1·최소1)+합계(판매가×수량, 실시간) ⑪장바구니 담기·바로구매.
- **정책**: 찜 → POL-WISH(회원, 개수 표기, 얼럿/토스트 없이 아이콘 토글이 피드백). 공유 → POL-COMMON(URL복사/카카오톡, 항상 노출). 적립 → POL-POINT/PRICE. 배송비 → POL-DELIVERY. 할인/적립 우선순위(교강사 추가>상품>일반) → UC-PNT-07/POL-BENEFIT.
- **제거 항목(신규 정책)**: 판매상태 라벨(좌측)·지사안내·좌측 구매하기·좌측 정가.

### 2-3. 관련정보 Tab 바 + 우측 구매영역 (UC-INFO-14)
- **Tab 9개(고정 순서)**: 학습자료 · **상세정보** · 학습법 · 시리즈 교재 · 다음단계 교재 · **추천교재** · 후기 · 정보고시 · 구매유의사항.
- **동작**: 전환형 아님 — 9개 섹션이 한 페이지에 순서대로 렌더. Tab 클릭 = 해당 섹션 앵커 스크롤+활성화, 직접 스크롤 = 스크롤스파이 자동 활성화. Tab 바 상단 이탈 시 sticky.
- **우측 구매영역(PC 전용)**: 적립안내·배송비안내·수량·합계·장바구니 담기·바로구매(HERO 우측과 동일 컴포넌트 재사용·값 동기화), 스크롤 내내 sticky. Mobile 미노출.
- **모바일 하단 CTA(Mobile 전용, 2026-08)**: 우측 구매영역 대신 하단 고정 바 `.pdp-bar` = 찜하기 · 장바구니 담기 · **구매하기**(舊 '바로구매' → **명칭 '구매하기'로 변경**). **구매하기 탭 → 수량선택 바텀시트** `.qty-sheet`(그래버 + 제목 '수량선택' + 스테퍼(−/수량/+)·금액[단가×수량 실시간] + 전체폭 빨강 '구매하기'). 하단 바는 푸터 도달 시 **푸터 위 20px 도킹**(`.docked` 그림자 제거).
- **비노출 규칙**: 데이터 없는 섹션은 Tab·콘텐츠 함께 비노출(나머지 순서 당겨짐), 전 섹션 0개면 영역 전체 비노출.

### 2-4. 학습자료 섹션 (UC-MAT-01 참조·UC-INFO-05)
- 자료대상 **전체·회원** 자료만 노출. 전체 다운로드(+개수)·유형별 다운로드. 교강사 전용 자료는 개별 노출하지 않고 **교강사 자료 바로가기**(NE Tutor, 로그인 무관 이동)로만 제공(→ UC-MAT-11).

### 2-5. 상세정보 (UC-INFO-06)
- 항목명 '교재 소개'→**'상세정보'**(변경). Admin 에디터 등록 Rich Text 그대로. 미등록 시 Tab 비노출.

### 2-6. 학습법 (UC-INFO-09)
- '권장학습법'→**'학습법'**(명칭만 변경). Admin 텍스트에디터 콘텐츠 그대로, 권한 분기 없음. 미등록 시 Tab 비노출.

### 2-7. 시리즈·다음단계·추천 교재 (UC-INFO-11/13/12) — 공통 카드 UI
- **상단 타이틀 행**: 타이틀명 · 총 권수(총 #권) · 전체선택 체크박스 · 선택 장바구니 담기 버튼.
- **카드**: 체크박스 · 썸네일(우측 하단 장바구니 아이콘 오버레이=개별 담기) · 카테고리 2단계명 · 상품명 · **판매가·정가만**(할인율·적립률·Hover 액션 없음).
- **동작**: 카드 아이콘=1권 개별 담기(UC-BUY-01), 상단 버튼=체크 묶음 담기(UC-BUY-04). 미선택 시 **알럿**. **4개 이상** 좌우 스와이프. 데이터 수동 큐레이션(Admin), 자동 알고리즘 없음.

### 2-8. 후기 (UC-INFO-10)
- 목록: 별점·이미지·제목·작성자/작성일. **'후기 등록' 버튼 → 고객센터>교재 후기>등록(UC-CS-13) 이동, 완료 시 교재상세 복귀**. 작성=회원(구매 무관), 최초 1회 500P(→ POL-REVIEW). 블라인드 미노출, 후기 없으면 Empty.

### 2-9. 정보고시 (UC-INFO-07)
- **필수 10종(2026-07-09 확정)**: 저자 · 출판사 · ISBN · 쪽수 · **크기** · **제품구성** · 발행일(출간일) · **KC인증코드** · **취급방법 및 주의사항** · 목차. Admin 등록 데이터 그대로. 미등록 시 Tab 비노출.

### 2-10. 구매유의사항 (UC-INFO-08)
- 반품/교환 방법·기간·비용·불가사유·배송안내·소비자 피해보상·기타를 **안내 텍스트(읽기 전용)**로만. 접수 버튼/폼 없음(실제 접수는 1:1문의, → POL-REFUND).
