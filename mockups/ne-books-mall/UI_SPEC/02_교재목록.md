# 교재목록 UI 스펙 (파일: 리스트_교재구매.html · 리스트_학습자료.html)

> NBR "교재목록" 화면. **교재구매 탭**과 **학습자료 탭** 두 목록유형을 하나의 화면 구조(사이드바 + 상단 시리즈 밴드 + 툴바 + 리스트 + 페이저)로 공유하며, 우측 상단 알약형 탭으로 전환한다. 레이아웃은 **리스트형(1열 카드) 고정**(앨범형 미제공, UC-FIND-06).

> **🟢 디자인 반영(2026-08)**
> - **교재구매 좌측 필터**: 첫 그룹 명칭 `레벨` → **`학습대상`** 으로 변경(옵션 유아·초등·중등·고등·성인 동일). 모바일 필터칩/필터시트도 '학습대상'으로 통일.
> - **교재구매 좌측 필터 `제품유형`**: `Class Pack` 체크박스 **비활성(disabled) → 일반(활성)** 으로 변경.
> - **학습자료 탭 좌측 필터**: 舊 `레벨`+`제품유형` 2그룹 삭제 → **`학습자료` 단일 그룹(11종)** 으로 교체 = Teaching Materials · 수업용 PPT · Word Lists · Answer Keys · MP3 · Test Sheet · Lesson Plans · Oxford · 정답 및 해설 · 부가문제 · 기타. (그 아래 `브랜드` 그룹 유지)
> - **더보기(모바일)**: 리스트 기본 10개 + `10개 더보기(N/414)` 버튼(테두리 #4D4E4D·Pretendard Medium 14). PC는 페이징 유지.

## 2. 화면 구성 (영역별)

### 2-1. 상단 시리즈 밴드 (`.catband` / `.cat-row .cat-card`) — 공통
- **관련 UC**: UC-FIND-05
- **UI 요구**: PC 필터 배치는 **시리즈=상단, 그 외 필터=좌측**으로 분리(2026-07-09 확정). 현재 HTML은 상단에 시리즈 카드 7종(파닉스가 된다·사이트 워드가 된다·GRAMMAR BUDDY·GRAMMAR BEAN·문법이 된다·Grammar Inside·Grammar Ten)을 가로 배치.
- **정책**: 시리즈=카테고리 3단계 데이터 연동(POL-CATALOG). 매칭 교재 0권 시리즈는 제거하지 않고 **비활성화(disabled)** 노출(전 필터 공통 규칙).
- **인터랙션**: 카드 선택 시 조건 조합 자동 재조회(단일 선택 성격).

### 2-2. 좌측 사이드바 필터 (`.sidebar / .fgroup / .fopt`)
- **관련 UC**: UC-FIND-05, UC-FIND-06
- **UI 요구(교재구매 탭)**: 시리즈(상단) 외 **레벨·제품유형·브랜드** 좌측 노출. 현재 HTML `레벨`(유아·초등·중등·고등·성인) / `제품유형`(메인교재·Word Book·Test & Worksheet·Tests·Teacher's Guide·Class Pack[disabled]) / `브랜드`(NE능률·Build & Grow·OXFORD 로고 체크박스).
- **UI 요구(학습자료 탭)**: PRD상 학습자료 필터 세트 = **시리즈·자료유형·브랜드**(레벨/제품유형 비노출). → 현재 HTML 학습자료 파일은 교재구매와 **동일 사이드바**(레벨/제품유형/브랜드)를 사용, `자료유형` 필터 없음(갭).
- **정책**: 매칭 데이터 0건 필터 항목은 비활성화(disabled) 노출. `Class Pack`은 disabled 예시로 구현됨(`.fopt:has(.chk:disabled)` 회색·not-allowed).
- **인기교재 NE차트 버튼(`.nechart`)**: ELT·초/중등·고등·수학/국어 하위 진입 시에만 노출, 클릭 시 `book_top10/search.asp` 이동(PRD). 현재 HTML은 진입 경로 무관 상시 노출, `href` 없음.
- **인터랙션**: 체크 시 자동 재조회(와이어프레임은 정적, 동작 미구현).

### 2-3. 툴바 (`.toolbar`) — 공통
- **관련 UC**: UC-FIND-06(유형 전환), UC-FIND-07(판매중만), UC-FIND-08(정렬)
- **좌측(`.tb-left`)**: `총 N개 상품` 카운트 + `판매중 교재만 보기` 체크박스.
  - UC-FIND-07: 체크 시 **구매 가능 3종(판매중·판매예정·절판예정)**만, 해제 시 **5종 전체**(일시품절·판매중단 표시). HTML 체크박스 존재, 동작 미구현.
- **우측(`.tb-right`)**: 알약형 유형 탭 `교재구매`/`학습자료`(`.tab`, active=`--red`) + 구분선 + 정렬 드롭다운.
  - UC-FIND-06: 두 유형 모두 리스트형 고정, 앨범형 토글 없음 → HTML 준수(그리드 옵션 없음).
- **정렬(`.sort-wrap / .sort-menu / .sort-opt`)**: 6종 `인기순·최신순·과거순·별점순·가나다순·역 가나다순`. 커스텀 드롭다운.
  - UC-FIND-08 기본값 = **최신순**. 현재 HTML 기본 active = **인기순**(불일치). 항목 순서도 PRD(최신순 우선)와 상이.
- **인터랙션**: 정렬 클릭 시 라벨 갱신·active 이동(구현됨). 재조회는 정적.

### 2-4. 리스트 — 교재구매 카드 (`.plist > .prow`) [교재구매 탭]
- **관련 UC**: UC-INFO-01, UC-INFO-04, UC-INFO-17
- **카드 구조(현재 HTML)**:
  - `.pcover`: 썸네일 + `.pcorner`(HOT `--red` / NEW `--blue` / soldout 회색) — **썸네일 좌상단 배지**(UC-INFO-04 준수).
  - `.pbrand-row`: 브랜드 로고 · `badge-course`(카테고리 2단계, 예: Coursebook) · `badge-level`(학습대상 범위, 예: 유치~초등(저)) · `badge-lexile`(Lexile 지수 텍스트 + info 아이콘, 클릭 시 툴팁).
  - `.ptitle`(상품명) · `.pdesc`(대표카피) · `.ptags`(주요키워드 #해시).
  - `.pactions`: `.picons`(공유 팝업 URL복사/카카오톡 + 찜 토글 `찜 128`) · `.pdiscount`(할인율 `할 10%` red / 적립률 `적 5%`) · `.pprice`(정가 취소선 + 판매가) · `.pbtns`(장바구니 + 바로구매).
- **정책 매핑**: 가격/적립 POL-PRICE, 판매상태 POL-SALE, 찜 POL-WISH(비회원 클릭 시 로그인 유도), 공유 POL-COMMON(항상 노출).
- **교과서 구매 예외(UC-INFO-01)**: `교과서 구매` 체크 교재는 `[구매하기]`→`[교과서 구매]`(새창 한국교과서협회) 대체 + **`[장바구니 담기]`는 비활성(disabled) 유지**. HTML 상품3은 `교과서 구매` 버튼만 노출하고 장바구니 버튼을 **제거**(비활성 유지가 아님 — 갭).
- **인터랙션**: 썸네일/제목 클릭→교재상세 이동(일시품절은 `?st=soldout`). 공유·찜·Lexile 툴팁·정렬 JS 구현.

### 2-5. 리스트 — 학습자료 카드 (`.plist > .prow` + `.pres`) [학습자료 탭]
- **관련 UC**: UC-INFO-02, UC-MAT-01/02/03/05/06/08/11
- **상단 메타·썸네일**: 교재구매 카드와 동일(브랜드·카테고리·학습대상·Lexile·HOT/NEW).
- **본문 우측 하단(`.pres`)** — 좌→우 3영역:
  - **부가서비스 바로가기**: `pres-item.qr` = 모바일학습(QR)·MP3음원(QR). QR 아이콘 + 명칭(UC-MAT-05/06, 로그인 무관 새창).
  - **학습자료 다운로드(`.pres-scroll`)**: 전체 다운(12)·정답(2)·MP3(5)·WordBook(3) 등 `자료유형 아이콘 + 자료명 + (개수)`. 다수 시 **좌우 드래그 스크롤** 구현(`.pres-scroll` drag-to-scroll).
  - **선생님 자료 바로가기(`.pres-tutor`)**: `NE_Tutor / 선생님 자료 바로가기` 아이콘 박스, 학습자료 영역 우측(UC-MAT-11).
- **`.pactions`**: 공유 + 찜만(가격/구매 버튼 없음 — 학습자료 유형 정상).
- **정책 매핑**: 다운로드 권한 POL-MATERIAL(UC-MAT-01, TODO-33 임시로 전체·회원 모두 로그인 필요, 예외자료 Answer Keys·정답 및 해설·MP3는 비로그인 즉시). 멀티다운로드=팝업(UC-MAT-02, 클릭 시). 선생님 자료 바로가기=로그인 무관 NE Tutor 상세 이동(UC-MAT-11).
- **자료대상 플래그(UC-MAT-08)**: 자료 항목별 `전체`/`회원` 배지 노출 필요 → 현재 HTML 미구현(아이콘+명칭+개수만, 배지 없음).
- **조건부 노출(UC-INFO-02, UC-MAT-11)**: 부가서비스·전체/회원 자료·선생님 자료 모두 없으면 카드 자체 미노출, 선생님 자료 바로가기는 E-Book/교강사 자료 있을 때만. HTML은 4개 카드 전부 동일 세트(모바일학습·MP3음원·전체다운·정답·MP3·WordBook·NE_Tutor)를 상시 노출(조건 분기 미표현).

### 2-6. Empty (`.no-result / .nr-ic / .nr-title / .nr-sub`)
- **관련 UC**: UC-FIND-10, UC-FIND-01
- **UI 요구**: 검색/필터 0건 시 안내. **PRD 확정 문구 = "일치하는 검색 결과가 없습니다."**(검색·필터 동일, 추천/초기화 미노출).
- **현재 HTML**: 교재구매 파일에만 `#noResult` 블록 + `?q=` 스크립트 구현(제목 매칭 → 0건 시 리스트/페이저 숨김·Empty 노출). 문구는 `검색한 결과가 없습니다.` + 서브 `상품을 다시 검색해 주세요.`(PRD 문구와 불일치). **학습자료 파일에는 Empty 블록·검색 스크립트 모두 없음**(갭).

### 2-7. 페이지네이션 (`.pager`)
- **관련 UC**: UC-FIND-09
- **UI 요구**: 페이지당 10개, 이전/다음, 1페이지 이하 단순화·미노출(POL-COMMON). HTML: `‹ 1(on) 2 3 4 5 ›` 숫자 + 화살표. 현재 페이지 강조(`.on` 검정 pill) 구현.
