# NE Times 후기이벤트 에디터

매월 **후기이벤트 상세페이지 1종 + 홍보 배너 6종**을 디자이너 없이 직접 제작하는 도구입니다.

`review-builder.html`을 브라우저로 열면 바로 실행됩니다. 설치·서버 불필요.

---

## 화면 구성

- **왼쪽** 미리보기 / **오른쪽** 편집 — 오른쪽에서 고치면 왼쪽에 즉시 반영됩니다.
- 왼쪽 위 `상세페이지` · `배너 6종` 탭으로 전환합니다.
- 상세페이지 탭의 `상단 · 혜택 · 작성방법 · 확인사항 · 푸터` 로 해당 위치로 바로 이동합니다.
- `이미지 만들기` → **업로드용 ZIP 한 벌** / **상세페이지 전체 1장** / **HTML 파일** 중 선택.

## 달마다 바꾸는 것

| 항목 | 편집 위치 |
| --- | --- |
| 테마 색 | 테마 컬러 — 프리셋 6종 또는 **메인 / 포인트** 2색 직접 지정 |
| 상단 기간·대상 | 상단 — `진행 월`만 고르면 기간 문구가 따라옵니다 |
| 상단 그림 | 상단 — 기본 일러스트 또는 **PNG 직접 올리기** (크기·좌우·상하 조절) |
| 혜택 큰 제목·안내 문구 | 혜택 |
| 등급별 조건·상품·인원·배지 | 혜택 — 베스트 후기 · 포토 후기 · 텍스트 후기 세 칸 |
| 등급별 상품 이미지 | 혜택 — 네이버페이 30,000 / 10,000 / 5,000원 · 직접 올리기 |
| 꼭 확인하세요 | 꼭 확인하세요 — `＋` / `−` 로 항목을 늘리고 줄임 |
| 푸터 문구·주소 | 푸터 |

**문구 안에서 강조**하려면 그 부분을 `*별표*`로 감쌉니다.
`*후기를 남겨주시는* 회원님들께` → `후기를 남겨주시는`만 포인트 색이 됩니다.
글자를 드래그한 뒤 `✦ 선택 강조` 버튼을 눌러도 됩니다.

## 색이 어디에 쓰이는지

| 색 | 쓰이는 곳 |
| --- | --- |
| **메인 컬러** | 상단·혜택 배경 · 참여방법 원 3개 · 배너 4종 배경 |
| **짙은 색** | 기간 띠 · 등급 띠 3개 · 작성방법 배경 (기본값은 메인의 70%) |
| **포인트 컬러** | 「후기」「선물」 레터링 · 혜택/후기 배지 · 등급 띠 글씨 · 하단 버튼 |

배경 계열(메인)과 강조 계열(포인트) 두 축만 쓰므로, 프리셋을 고르면 페이지 전체가 한 벌로 맞습니다.

## 손대지 않아도 되는 것

- **기간 문구** — `진행 월`만 고르면 `26년 8월 1일 – 26년 8월 31일`처럼 말일까지 자동으로 맞습니다.
  다르게 쓰려면 `기간 문구 자동` 체크를 끄세요.
- **작성방법 섹션**(수강 후기 작성은 이렇게 해요!) — 글·아이콘·버튼이 모두 고정입니다.
  색만 테마를 따라갑니다.
- **「리얼후기 쓰고 선물득템 하자!」 레터링** — Figma에서 뽑은 그림이라 문구는 못 바꿉니다.
  대신 **색은 테마를 따라갑니다.** 흰 글자는 메인 컬러가 밝아지면 저절로 어두워지고,
  노란 글자는 포인트 컬러로 바뀝니다. 연필은 그대로 둡니다.
- **배너 6종** — 상세페이지의 테마 컬러와 상단 그림을 그대로 따라갑니다. 따로 편집할 것이 없습니다.
- **글자 색 대비** — 밝은 테마를 고르면 배경 위 글자가 자동으로 어두워집니다.
- **배너 배경색 2종은 디자인 가이드로 고정입니다.**
  `[PC]메인 449×470` = **#F8F8F8** · `[PC]GNB펼침 150×175` = **#FFFFFF**.
  이 두 장만 레터링이 흰색 대신 **메인 컬러 + 진한 포인트 컬러**로 들어갑니다.
  나머지 4종(커뮤니티 · 영자신문 2종 · 모바일메인)은 메인 컬러 배경입니다.
- **꼭 확인하세요 띠**(#4C4C4C)와 **푸터 흰 바탕**은 테마와 무관하게 고정입니다.

## 업로드용 ZIP

`이미지 만들기` → `업로드용 ZIP 한 벌` 을 누르면 등록에 쓰는 구성 그대로 **12장**이 나옵니다.
폴더 이름·파일 이름·이미지 크기는 `NETimes_10월후기이벤트_이미지.zip` 과 동일합니다.

```
NETimes_10월후기이벤트_이미지.zip
└─ NETimes_10월후기이벤트_이미지/
    ├─ 업로드_10/
    │   01.png(950×1115)  02.png(950×1624)  03.png(950×910)
    │   04.png(950×466)   05.png(950×124)   btn_01.png(662×126)
    └─ 배너/
        [MO]1080x700모바일메인.png       [PC]449x470메인.png
        [PC]535x409커뮤니티.png          [PC]724x170영자신문.png
        [PC]_150x175_GNB.png            [PC_MO]542x170영자신문.png
```

`01` 상단 · `02` 혜택 · `03` 작성방법 · `04` 꼭 확인하세요 · `05` 푸터 순서입니다.

**`03`에는 노란 버튼이 들어가지 않습니다.** 버튼은 링크를 걸어야 해서 `btn_01.png`로 따로 나갑니다
(662×126, 모서리 둥근 투명 PNG). 미리보기에서는 제자리에 그대로 보이고, 내보낼 때만 빠집니다.

## 상단 그림 바꾸기

기본은 휴대폰·선물·말풍선 일러스트입니다. `상단` → `상단 그림`에서 **직접 올리기**를 누르고
PNG를 올리면 그 자리에 들어갑니다.

- 들어가는 자리는 레터링 아래 **950×516**입니다. 비율을 지켜 가운데 맞춤으로 들어가고,
  자리를 벗어나는 부분은 잘립니다. **배경이 없는 PNG**가 가장 깔끔합니다.
- `크기` · `좌우` · `상하` 슬라이더로 위치를 미세 조정합니다. 틀어지면 `위치·크기 초기화`.
- `배너 6종에도 같은 그림 쓰기`를 켜 두면 **배너 6종도 같은 그림으로 바뀝니다.**
  배너는 규격이 제각각이라 슬라이더 값은 따르지 않고, 각 배너의 그림 자리에 비율을 지켜 자동으로 맞춥니다.
  체크를 끄면 배너만 기본 일러스트로 남습니다.
- `올린 이미지 지우기`를 누르면 기본 일러스트로 돌아갑니다.

올린 이미지는 설정 JSON 안에 같이 저장됩니다. 용량이 크면 브라우저 자동 저장이 실패할 수 있으니
(`자동 저장 실패 — 이미지 용량 초과`) 그럴 때는 `설정 저장`으로 파일을 받아 두세요.

## 다음 달 작업

1. `설정 저장` → JSON 파일을 받아 둡니다.
2. 다음 달에 `불러오기` → 그 파일을 선택합니다.
3. 진행 월·상품 문구·이미지만 교체합니다.

브라우저에 자동 저장되지만 **PC가 바뀌면 사라집니다.** 매달 JSON을 받아 두세요.

## 알아둘 점

- 폰트(Paperlogy·Gmarket Sans·Pretendard)와 이미지 변환 라이브러리를 인터넷에서 받아옵니다.
  **처음 열고 2~3초 뒤에** 이미지를 만드세요. 폰트가 덜 실린 상태로 만들면 글자가 겹쳐 찍힙니다.
- **상단에는 원래 상품 이미지가 없습니다.** 매달 주는 상품이 네이버페이로 고정이 아니라서,
  상품이 바뀔 때마다 상단까지 다시 만들지 않으려고 뺀 것입니다. 필요할 때만 `상단 그림`으로 올리세요.
- **상품 이미지**는 네이버페이 금액권 3종 중 하나를 고르거나 직접 올립니다.
  들어가는 자리는 290×290이라 **정사각형·배경이 없는 PNG**가 가장 깔끔합니다.
- **원형 배지**(매월 3명)와 **인원** 칸은 따로 입력합니다. 숫자를 바꿀 때 둘 다 고쳐 주세요.
- `HTML 파일`로 받으면 글자가 실제 텍스트라 확대해도 깨지지 않고 복사·검색이 됩니다.
  웹 편집기에는 파일 내용을 그대로 붙여넣으면 됩니다.
