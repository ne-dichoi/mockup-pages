# NE Times 레벨테스트 에디터

매월 전화화상영어 **무료레벨테스트 상세페이지**를 디자이너 없이 직접 제작하는 도구입니다.

`leveltest-builder.html`을 브라우저로 열면 바로 실행됩니다. 설치·서버 불필요.

## 화면 구성

- **왼쪽** 미리보기 / **오른쪽** 편집 — 오른쪽에서 고치면 왼쪽에 즉시 반영됩니다.
- 왼쪽 위 `상세페이지` · `배너·버튼` 탭으로 전환합니다.
- 상세페이지 탭의 `상단 · 이벤트 · 부가서비스 · 후기 · 확인사항 · 푸터` 로 해당 위치로 바로 이동합니다.
- `이미지 만들기` → **업로드용 ZIP 한 벌** / **상세페이지 전체 1장** / **HTML 파일** 중 선택.

| 하단 플로팅 버튼 문구 | 하단 플로팅 버튼 — 왼쪽 `자세히보기` · 오른쪽 `신청하기` |

### 색이 어디에 쓰이는지

| 색 | 쓰이는 곳 |
| --- | --- |
| **메인 컬러** | 상단 배경 · NE Times Talk 배경 · 섹션 제목 3개(부가서비스 혜택 · 다양한 영어뉴스 과정 · 생생 수기 후기) · 부가서비스 말풍선 덩어리 · 후기 이름표 |
| **연한 배경** | 이벤트 영역 윗부분 |
| **포인트 컬러** | 상단 월 배지 · 이벤트 강조 문구 · 참여방법 STEP 제목과 아이콘 |

배경 계열(메인)과 강조 계열(포인트) 두 축만 쓰므로, 프리셋을 고르면 페이지 전체가 한 벌로 맞습니다.

**문구 안에서 강조**하려면 그 부분을 `*별표*`로 감쌉니다.
`*네이버페이 5,000원*을` → `네이버페이 5,000원`만 포인트 색이 됩니다.
글자를 드래그한 뒤 `✦ 선택 강조` 버튼을 눌러도 됩니다.

## 손대지 않아도 되는 것

- **기간 문구** — `진행 월`만 고르면 `2026년 8월 1일 ~ 8월 31일`처럼 말일까지 자동으로 맞습니다.
  다르게 쓰려면 `기간 문구 자동` 체크를 끄세요. 길게 써도 오른쪽 끝에 맞춰 **항상 한 줄**로 나옵니다.
- **펼쳐 둔 편집 패널** — 항목을 더하거나 지워도, 테마를 바꿔도 펼친 상태와 스크롤 위치가 그대로입니다.
  `＋ 항목 추가`를 누르면 새 항목이 바로 펼쳐지고 문구 칸에 커서가 들어가 곧장 타이핑할 수 있습니다.
- **글자 색 대비** — 어두운 테마를 고르면 상단 로고·작은 제목·기간이 흰색으로 자동 전환되고,
  레몬처럼 밝은 테마를 고르면 큰 제목이 짙은 색으로 바뀝니다.
  섹션 제목과 말풍선 덩어리도 회색 배경 위에서 읽히도록 필요한 만큼만 어두워집니다.
- **NE Times Talk · 부가서비스 혜택 · 다양한 영어뉴스 과정 · 생생 수기 후기**
  — 글이 고정이고 테마 컬러만 따라갑니다. 편집할 것이 없습니다.
- **후기 6장**은 5초마다 자동으로 넘어갑니다(30초에 한 바퀴). 아래 막대도 함께 움직입니다.
  이미지로 내보낼 때는 첫 장에서 멈춰 찍고, 6장을 각각 따로 저장합니다.
- **배너 배경색은 디자인 가이드로 정해져 있습니다.** 테마 컬러를 따라가지 않으니 고치지 마세요.
  `[PC]메인 449×470` = **#F8F8F8** · `[PC]GNB펼침 150×175` = **#FFFFFF** ·
  나머지 4종(커뮤니티 · 영자신문 2종 · 모바일메인) = 메인 컬러.
- **상단 그림**은 기본이 Figma 원본(소녀 일러스트 + 오브제)입니다. 프리셋이나 올린 그림을 고르면
  오른쪽 제목을 피해 **왼쪽 아래**에 자동으로 앉습니다. 그림의 투명 여백을 걷어 내고 자리를 잡으므로
  그림마다 크기가 들쭉날쭉하지 않습니다. 더 옮기려면 `크기` · `좌우` · `상하` 슬라이더를 쓰세요.
- 기본이 아닌 그림을 고르면 **배너 6종도 같은 그림**을 씁니다(`배너 6종에도 같은 그림 쓰기` 체크).
  배너는 규격이 제각각이라 슬라이더를 따르지 않고 가로 가운데·세로 바닥에 자동으로 맞춥니다.
  직접 올릴 때는 **배경이 없는 PNG**가 가장 깔끔합니다.
- **배너 6종과 하단 플로팅 버튼**은 상세페이지의 색·월·기간을 그대로 따라갑니다.
  `배너·버튼` 탭에서 확인만 하면 되고, 따로 편집할 것이 없습니다.
- **동영상 자리**(검은 박스 2개) — 실제 페이지에서 영상으로 교체하는 영역이라 그대로 둡니다.

3. 진행 월·이벤트 문구·색만 교체합니다.

브라우저에 자동 저장되지만 **PC가 바뀌면 사라집니다.** 매달 JSON을 받아 두세요.

## 알아둘 점

- 폰트(Gmarket Sans)와 이미지 변환 라이브러리를 인터넷에서 받아옵니다.
  **처음 열고 2~3초 뒤에** 이미지를 만드세요. 폰트가 덜 실린 상태로 만들면 글자가 겹쳐 찍힙니다.
- **이벤트 상품 이미지**는 카드 다섯 장 중 하나를 고릅니다 — `아이스 아메리카노` · `따뜻한 아메리카노` ·
  `네이버페이 금액권` · `카카오페이 금액권` · `직접 올리기`. 기본값은 아이스입니다.
  직접 올릴 때는 **배경이 없는 PNG**가 가장 깔끔합니다.
- **페이 금액권**을 고르면 `금액권에 찍히는 금액` 칸이 나타납니다. `5,000원`, `10,000원`처럼
  쓰는 대로 카드 오른쪽 아래에 들어갑니다. 네이버·카카오 모두 편집됩니다.
- 아이스·따뜻한 위에 얹힌 **초록 원과 별**은 스타벅스 로고를 가리는 장치라
  직접 올린 이미지에는 들어가지 않습니다.
- 「모바일 쿠폰 제공」 **말풍선**은 세 가지 모두에 그대로 남습니다. 필요 없으면 아래 체크를 끄세요.
  위치는 고정이라 옮길 수 없습니다.
- `HTML 파일`로 받으면 이미지가 아니라 실제 텍스트라 확대해도 깨지지 않고 복사·검색이 됩니다.
  웹 편집기에는 파일 내용을 그대로 붙여넣으면 됩니다.
