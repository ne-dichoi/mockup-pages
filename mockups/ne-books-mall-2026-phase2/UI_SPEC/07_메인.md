## 2. 영역별 구성

### 2-1. 최상단 큐레이션/이벤트 배너 (`.hero2` / UC-PROMO-06)
- **관련 UC/정책**: UC-PROMO-06 · Admin UC-ADM-SITE-03
- **UI 요구사항 (PRD 최신, 2026-07-31)**
  - **메인 최상단**에 **중앙 포커스 무한 캐러셀** — 화면 중앙 큰 카드 1장 + 양옆으로 앞/뒤 배너가 무한 루프로 걸쳐 보임. 자동 롤링 기본 5초·무한 루프, 호버/조작 시 정지·재개.
  - 노출: 노출여부=노출 + 노출기간 내 배너를 **관리자 지정 순서(우선순위)순, 최대 10건**.
  - **카드 구성**: 배경색(관리자 HEX) · 이미지 7:8(350×400px)·라운드 16px(구분=교재는 교재 이미지 자동, 프로모션은 등록 이미지) · **좌상단 키워드 플래그=자유입력 문구, 글자색만(배경 없음)** · 메인텍스트(제목 최대 2줄 말줄임) · 서브텍스트(설명).
  - 인디케이터: 하단 진행바 + 현재/전체 + 좌우 화살표(Mobile 스와이프). **PC=Mobile 반응형 동일**(양옆 노출량만 화면 폭에 비례, 가장 넓은 PC가 최대 노출).
- **현재 HTML**: `.hero2` 중앙 포커스 무한 캐러셀 구현(5초 자동 롤링·무한 루프·드래그·좌우 화살표·진행바·현재/전체) — **캐러셀 메커니즘은 일치**. 단 카드(`.hero2-card`)는 **전체 이미지 1장(object-fit:cover)** 만 표시하는 舊 통배너형 → 키워드 플래그·배경색·7:8 규격·메인/서브 텍스트 미구현.

### 2-2. 바로가기 영역 (`.mainicons` / UC-PROMO-03)
- **관련 UC/정책**: UC-PROMO-03 · POL-LINK · POL-MATERIAL
- **UI 요구사항**: **PC 7종**(교재 구매·레벨차트·학습자료실·정답·MP3 다운·음원듣기·영어 선생님·수학 선생님), **Mobile 8종**(+맞춤형 교재추천). 항목별 라우팅(§5 매핑). `음원듣기`=舊 NE Waffle 명칭만 변경(라우팅 동일). 학습자료실→교재목록(학습자료 탭 기본). 선생님 2종→NE Tutor 영어/수학 메인(새창, 로그인 시 SSO).
- **현재 HTML**: `.pill` 7종 — 교재 구매 / 레벨차트 / 학습자료실 / 정답·MP3 다운 / **MP3 듣기** / 영어 선생님 / 수학 선생님. (바로가기 `NE Waffle→음원듣기`를 이번 세션에 다시 `MP3 듣기`로 라벨 교체·반영, 라우팅 동일)

### 2-3. 베스트셀러·프로모션(기획전) 탭 (`.bestseller` / UC-PROMO-04·05)
- **관련 UC/정책**: UC-PROMO-04 · UC-PROMO-05(묶음담기) · UC-BUY-01/04 · POL-PRICE · POL-SALE · POL-CART
- **UI 요구사항**
  - 코스 탭(밑줄/알약) 전환 → 코스별 홍보 문구 + 교재 카드 **최대 5건**.
  - 교재 카드: 표지 · **NEW/HOT 뱃지** · 학년군·영역 태그 · 교재명 · 가격(**정가/할인가/할인율**) · **상세보기 버튼** · 장바구니 버튼 · 선택 체크박스.
  - PC=좌측 코스 홍보 카드([장바구니 담기] 묶음 버튼)+우측 교재 카드 그리드(정보 통합). MO=표지 카드 가로 스와이프 + 하단 교재 리스트 분리 + 최하단 묶음 버튼.
  - 개별 장바구니=단건 담기(UC-BUY-01). 코스 [장바구니 담기]=체크 교재 **묶음담기**(UC-PROMO-05, **디폴트 모두 선택**). 담기 성공 얼럿("상품이 장바구니에 담겼습니다. 장바구니로 이동하시겠습니까? 확인/취소"). 선택 0건 시 얼럿("선택된 교재가 없습니다."). 품절 제외.
- **현재 HTML**: `.bs-head`(제목 "베스트셀러" + 코스 탭 5개) + `.bs-row`(좌 `.bs-promo` 홍보카드·[장바구니 담기] btn / 우 `.bs-list`). 교재 카드는 JS로 **6장 생성**. 카드=표지·체크박스·장바구니 아이콘·영역 태그(Phonics)·교재명·가격(정가/할인가). 카트 아이콘 클릭→`장바구니.html` 이동.

### 2-4. NE Tutor 진입 영역 (`.netutor` / UC-PROMO-07)
- **관련 UC/정책**: UC-PROMO-07 · POL-LINK
- **UI 요구사항**: '선생님을 위한 티칭 플랫폼 NE Tutor'. 서비스 6종(E-Book 교재자료·어휘 문제 마법사·문법 문제뱅크·NELT·성취 TEST·문법 예문 검색)을 **아치형(곡선) 좌우 롤링 캐러셀**로 노출(활성 카드 중앙 강조). 버튼 클릭→각 netutor.co.kr URL 새창 랜딩, 로그인 시 SSO 전달. 어휘 마법사 비로그인→선생님 로그인 안내. PC·Mobile 동일(모바일은 세로 스택).
- **현재 HTML**: `.nt-wrap` 아치(`netutor_arc.svg`) + 중앙 로고/카피 + `.nt-card` 6종(위 6서비스 동일) 아치 배치. 휠/클릭/스와이프로 좌우 롤링, 중앙 카드 red 강조·아이콘 반전. `≤1000px`에서 아치 해제·카드 flex 세로 스택.

### 2-5. 공지사항 (`.notices .notice-col` / UC-PROMO-08)

- **관련 UC/정책**: UC-PROMO-13 · UC-PROMO-10 · POL-COMMON · POL-INQUIRY
