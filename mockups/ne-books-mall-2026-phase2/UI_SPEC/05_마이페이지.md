# 마이페이지 UI 스펙 (파일: 마이페이지.html · 주문상세.html · 문의답변상세.html · 후기작성.html · 후기수정.html)

## 1. 화면 개요

- **구성 UC**
  - 홈: UC-CS-14(마이페이지 홈·메뉴 레이어) · UC-CS-15(최근 본 학습자료/교재 위젯) · UC-AUTH-05(회원정보수정 진입)
  - 주문내역: UC-ORD-15(조회/검색) · UC-ORD-16(주문상세) · UC-ORD-17(배송조회) · UC-ORD-18(구매확정) · UC-ORD-19(주문취소) · UC-ORD-20(환불정보)
  - 포인트: UC-PNT-04(현재/소멸예정) · UC-PNT-05(내역) · UC-PNT-06(안내)
  - 찜: UC-BUY-14(목록) · UC-BUY-15(해제/전체삭제) · UC-BUY-16(카드 장바구니 담기)
  - 문의/답변: UC-CS-07(목록/조회) · UC-CS-09(주문번호 연계) · UC-CS-12(답변 알림)
  - 후기: UC-CS-13(후기 목록/작성·수정·삭제)
  - 이벤트/세미나: UC-CS-04(참여내역 — 상세 스펙은 고객센터 문서 소관)
- **진입경로**: PC 헤더 `MY페이지` 아이콘(클릭=홈, hover=메뉴 레이어) / MO 햄버거 드로어 > 마이페이지 아코디언 / 마이페이지 상단 탭바.
- **로그인 요건**: 전 영역 로그인 회원 전용(POL-MEMBER). 비회원 접근 시 로그인 유도(→ UC-AUTH-03). 타인 데이터(주문·문의·찜·포인트) 직접 URL 접근 차단(POL-COMMON 비정상 접근 차단).
- **탭 구조(MY-001)**: 상단 탭바 순서 = **홈 · 주문내역 · 포인트 · 찜 · 문의/답변 · 후기 · 이벤트/세미나**(2026-07-28 디자인 확정 순서, 舊 '찜·포인트'→'포인트·찜'). 메뉴 레이어에는 여기에 `회원정보수정 · 로그아웃` 2종을 더해 9종. 목록↔상세는 탭바 고정 + 콘텐츠 영역만 전환.

## 2. 화면 구성 (영역별)

### 2-1. 홈 탭 (`#tab-home`)
- **관련 UC**: UC-CS-14 · UC-CS-15 · UC-AUTH-05
- **UI 요구사항**
  - **환영 배너**: `{이름} 선생님, 환영합니다.`(교강사) / `{이름}님, 환영합니다.`(일반) — 이름 볼드. 실패 시 `환영합니다.` 폴백. 배너 내 `회원정보수정`(밑줄버튼 → 통합회원 화면, UC-AUTH-05).
  - **활동 요약**: 문의·답변·세미나·후기 4종 건수 타일, 클릭 시 해당 탭 이동(0은 `0` 표기).
  - **주문 현황**: 입금대기·결제완료·배송중·배송완료 4단 요약 + [주문내역 보기 ›] → 주문내역 탭.
  - **포인트 요약**: 사용가능 포인트 + 30일 이내 소멸예정 포인트(빨강) + [포인트 내역 ›].
  - **최근 본 학습자료**: 최대 4개, 각 항목 교재명·자료명·대상 표기, 클릭 시 **교재상세 이동**(UC-CS-15).
  - **찜한 상품**: 카드 그리드 + [전체보기 ›] → 찜 탭. **최근 본 상품**: 카드 그리드. (2026-08 명칭: 舊 '찜한 교재'·'최근 본 교재' → '찜한 상품'·'최근 본 상품')
  - **🟢 모바일(Figma 2175-15398)**: 탭 숨김 → 홈 허브. 인사배너(핑크)+통계 4카드, 주문현황·포인트·최근본학습자료=테두리 박스(안 여백 24), 찜한 상품·최근 본 상품=가로 스크롤 카드.
- **정책**: POL-MEMBER(회원전용) · POL-ORDER/POINT/WISH(읽기전용 집계) · 나의 정보에 **'회원구분' 라벨 미표기**(호칭으로만 반영) · **쿠폰 라벨/영역 미노출, 포인트만 노출**.
- **인터랙션**: 위젯 `data-goto`로 탭 전환, 카드 장바구니 아이콘은 담기 처리.

### 2-2. 주문내역 탭 (`#tab-orders`)
- **관련 UC**: UC-ORD-15(기준 문서) · 16 · 17 · 18 · 19 · 20
- **UI 요구사항**
  - **검색영역**: 주문일자 시작~끝(캘린더, 기본값 **당해년도** 연초~오늘) + 검색어(placeholder "주문번호 또는 상품명을 입력하세요") + [검색].
  - **목록 행**: 썸네일 · 주문일자 · 주문상태 배지 · 상품명(여러 건이면 "{첫 상품명} 외 N건") · 주문번호(NB+YYYYMMDD+순번6) · 결제금액 + [영수증] · 상태별 액션 버튼.
  - **주문상태 9종**(POL-ORDER): 입금대기 / 결제완료 / 배송준비중 / 배송중 / 배송완료 / 구매확정 / 입금취소 / 결제취소 / **환불완료**.
  - **상태별 액션 버튼**(UC-ORD-15):
    | 상태 | 버튼 |
    |---|---|
    | 입금대기 | [입금취소] (7일 이내, 클릭/7일경과 시 소멸·입금취소 전환) |
    | 결제완료 · 카드/계좌이체/간편결제 | [결제취소] (취소사유 팝업, PG 자동환불) |
    | 결제완료 · 무통장입금(가상계좌) | **[반품/환불]** (결제취소 버튼 아님 — 입금완료 자금) |
    | 배송준비중~배송중 | [배송조회] [반품/환불] |
    | 배송완료 | [구매확정] [배송조회] [반품/환불] |
    | 구매확정 · 입금취소 · 결제취소 · **환불완료** | **버튼 없음(최종 상태)** |
  - **취소사유 14종**(결제취소·반품/환불 공통, 택1): 고객변심/결제변경/다른상품구매/배송지연/배송오류/배송불가지역/포장불량/상품 불만족/상품정보상이/상품불량/서비스불만족/품절/기타/직접입력.
  - **반품/환불**: 1:1문의로 이동(UC-CS-11), 무통장입금 건은 환불계좌(은행·계좌번호)·예금주명 추가 입력(모두 필수). 운영자 PG 콘솔 수동 처리 → Admin 완료 시 "환불완료" 자동 전환.
  - **주문 상태안내**: 4단계(입금대기/결제완료/배송중/배송완료) 설명 + 안내문구. 구매확정 기준 = **배송완료 후 7일**.
- **정책**: POL-ORDER · POL-PAYMENT · POL-REFUND · POL-CONFIRM · POL-COMMON(폼 유효성·페이징 10개).
- **인터랙션**: 상품명/썸네일 클릭 → 주문상세 뷰(탭바 고정·콘텐츠 영역만 전환, UC-ORD-16).

### 2-3. 주문상세 뷰 (주문상세.html / UC-ORD-16)
- **영역 구성**
  1. **주문상품**: 주문번호 · 상품별 썸네일·상품명·수량·판매가 · 주문상태(목록과 동일 상태값).
  2. **결제정보**: 결제수단명(무통장입금이면 은행·계좌번호·계좌명·입금기한 추가) · 주문금액 · 배송비 · 포인트 사용 · 결제일 · 최종 결제금액 · 적립예정 포인트.
  3. **취소정보** *(주문상태=결제취소·입금취소일 때, `#odCancel` 상태 주입)*: 취소일자 · 취소사유(취소사유 14종 옵션 목록).
  4. **배송지정보**: 이름 · 휴대폰 · 주소 · 요청사항.
  5. **환불정보** *(주문상태=환불완료일 때만, UC-ORD-20 · 취소정보 자리에 타이틀만 '환불 정보')*: 취소일자 · 환불사유(=취소사유와 동일 옵션) · 환불계좌(`[환불은행명] 환불계좌번호 / 환불계좌 예금주`).
  - **상태별 액션 버튼**은 목록(UC-ORD-15)과 동일 조건·동작으로 상세에서도 제공. **🟢 반영(2026-08)**: 주문상세 우측 상태 영역(`.od-status`)에서 상태 라벨 아래에 목록과 동일한 `.oh-btn` 세트를 세로 배치 — 결제완료=[결제취소] / 배송중=[배송조회·반품/환불] / 배송완료=[배송조회·반품/환불·구매확정] / 입금대기=[입금취소] / **구매확정·입금취소·결제취소·환불완료=버튼 없음(최종 상태)**.
- **정책**: 취소정보(결제취소)와 환불정보(환불완료)는 **배타적** — 한 주문이 두 영역을 동시에 갖지 않음.

## 3. 상태·예외

- **Empty**: 주문/포인트/문의/후기/찜 0건 → 각 Empty. 검색 0건 "일치하는 검색 결과가 없습니다."(POL-COMMON, 추천·필터초기화 미노출). 최근 본 항목 없음 → "최근 본 항목이 없습니다".
- **권한**: 비회원 직접 URL → 로그인 유도. 타인 주문/문의/찜/포인트 → 차단.
- **포인트 음수(−)**: 회수로 사용가능 포인트 음수 가능, (−) 표기 + 하단 안내문구.
- **주문상태 자동전환**: 입금대기 7일 미입금 → 입금취소 / 배송완료 7일 → 구매확정 / Admin 환불 완료 → 환불완료.
- **부분 실패 격리**(홈): 위젯별 조회 실패 시 해당 위젯만 0/Empty, 나머지 정상 렌더.
